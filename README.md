# Virtual Engineering Laboratory (VTU Aligned)

This project is a VTU-aligned Virtual Engineering Laboratory developed to help students understand experiments through:
- Aim and theory
- Step-by-step procedure
- Interactive inputs
- Results and feedback
- Viva questions

## Departments Supported
- Chemical Engineering
- Data Science

## Features
- VTU syllabus aligned experiments
- Theory before experiment
- Generic experiment engine
- Scalable to multiple departments
- Student-friendly UI

## How to Run the Project

### 1. Install Python
Download from: https://www.python.org/downloads/

### 2. Install Required Libraries
Open terminal / command prompt inside the project folder and run:

pip install -r requirements.txt

### 3. Run the Application

python -m streamlit run app.py

The application will open automatically in your web browser.

## Intended Users
- Engineering students
- Faculty members
- Institutions following VTU syllabus

## Purpose
To provide an interactive, easy-to-understand virtual lab experience that complements physical laboratory experiments.
